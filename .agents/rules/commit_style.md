# Git Commit Style Guidelines

When crafting git commit messages for changes in this repository:

1. **Multi-commit structure**: Break changes into multiple logical commits based on functional area (e.g., application code vs infrastructure).
2. **Commit Subject / Title**:
   - Keep it short, casual, humorous, or funny.
   - Use emojis freely.
3. **Commit Body / Description**:
   - Provide a stark contrast to the subject title.
   - Make it thoroughly professional, serious, informative, and detailed.
   - Document specific architectural changes, updated configuration keys, dependency modifications, and runtime behaviors.
